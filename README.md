# CC-Link IE Field 协议包 — 需 CC-Link IE Field 网关桥接

> [English](README.en.md)

CC-Link IE (Industrial Ethernet) Field 工业以太网版本，千兆以太网。需要 CC-Link IE Field 网关，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-cclinkie
```

## 功能

CC-Link IE Field 桥接、BridgeConnector 连接管理

## 所需硬件

CC-Link IE Field 网关

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- CC-Link IE Field 网关
- erikwang2013/industrial-protocols-kernel
